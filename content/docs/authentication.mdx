| 方式 | 怎麼帶 | 用途 |
|---|---|---|
| 匿名 | 不帶 | 公開讀取，每分鐘 60 次 |
| API Key | `Authorization: Bearer shuoshuo_live_...` | 你的程式；額度較高，也可依 scope 寫入 |
| 使用者 JWT | `Authorization: Bearer <JWT>` | 網站登入後由瀏覽器使用，第三方應用用不到 |

<Callout type="warn">憑證只能放在 `Authorization` 標頭。放在查詢字串會回 400 `CREDENTIAL_IN_QUERY`。</Callout>

## API Key

格式是 `shuoshuo_live_<8 字元公開 ID>_<43 字元祕密>`。

- 明文只在建立與重新產生時出現一次；伺服器只保存雜湊，弄丟了也無法找回，請重新產生。
- 每個帳號最多 10 組有效金鑰，沒有過期時間。
- 刪除或重新產生後，舊金鑰**最多 15 秒內**失效。
- 帳號被停權時，所有金鑰都會撤銷，**解除停權後不會恢復**，需要重新建立。

## Scope

建立金鑰時選擇，事後不能修改，需要不同權限就建立新的一組。

| Scope | 允許 | 預設 |
|---|---|---|
| `quotes:read` | 所有公開讀取，以及任何使用者**已公開**的按讚與收藏清單 | 一定包含 |
| `quotes:write` | 提交、編輯與刪除自己的說說 | 否 |
| `reactions:write` | 按讚、收藏 | 否 |
| `comments:write` | 新增、編輯與刪除自己的留言；置頂自己說說下的留言 | 否 |
| `me:read` | 我的提交、收藏、按讚與說說狀態；即使設為不公開，也能讀取自己的清單 | 否 |

權限不足時回 403 `INSUFFICIENT_SCOPE`，`details.required_scope` 會說明缺少哪一個。

## API Key 不能做的事

以下操作只接受登入憑證，帶 API Key 會回 403 `API_KEY_NOT_ALLOWED`：

- 檢舉
- 管理 API Key
- 修改使用者名稱與隱私設定
- 申訴與查看違規紀錄
- 刪除帳號
- 管理 API

## 重新驗證

建立或重新產生 API Key、刪除帳號需要 10 分鐘內驗證過身分，否則回 403 `REAUTH_REQUIRED`。網站會引導你重新登入一次。

## 帳號狀態

| 狀態 | 能做的事 |
|---|---|
| 正常 | 全部 |
| 暫停提交 | 不能提交與編輯說說、不能新增與編輯留言，其餘正常；既有 API Key 仍可使用 |
| 停權 | 只能登入查看原因、申訴與刪除帳號；所有 API Key 已撤銷 |

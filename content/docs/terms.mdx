使用 API 即表示你同意說說的[服務條款](https://shuoshuotw.xyz/terms)與[隱私權政策](https://shuoshuotw.xyz/privacy)。以下是與開發者最相關的部分。

## 內容

- 說說與留言由使用者提交，內容由提交者負責。API 不保證內容正確，也不保證出處無誤。
- 說說與留言是純文字。顯示在你的網站或程式之前，必須自行跳脫，詳見[安全](/security)。
- 被確認違規的說說會被移除，之後查詢會回傳 `410`。

## 呼叫方式

- 遵守[頻率限制](/rate-limits)，收到 `429` 時依 `Retry-After` 退避。
- API Key 不要放在網頁前端或使用者拿得到的地方，外洩時請到[個人中心](https://shuoshuotw.xyz/me/api-keys)重新產生或刪除。
- 不得用 API 規避處分，或以自動化方式大量寫入。帳號被停權時，它的所有 API Key 都會撤銷。

## 變更與可用性

- API 依現況提供，不保證不中斷。
- `/v1` 內的變更會記錄在[版本紀錄](/changelog)。

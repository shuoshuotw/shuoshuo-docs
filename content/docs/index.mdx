## 想要更多資訊

拿掉 `format=text` 會回傳 JSON，包含類別、來源與提交者：

```bash
curl "https://api.shuoshuotw.xyz/v1/quotes/random"
```

## 只要某些類別

```bash
curl "https://api.shuoshuotw.xyz/v1/quotes/random?categories=anime,game&max_length=40"
```

類別 key 列在[類別](/concepts/categories)。
